## ✨ Tentang Proyek

Miee Ayamm Archives adalah website penyimpanan tugas kuliah berbasis web yang membantu mahasiswa mengelola berbagai dokumen akademik dalam satu tempat.

Website ini dibuat dengan tampilan modern, sederhana, dan responsif sehingga nyaman digunakan baik melalui laptop maupun perangkat mobile.

---

## 🚀 Fitur Utama

- 📂 Penyimpanan arsip tugas kuliah
- 🔍 Pencarian dokumen cepat
- 📑 Kategori berdasarkan mata kuliah
- 🎓 Detail informasi tugas
- 📱 Responsive Design
- ⚡ Performa ringan dan cepat

## ⚙️ Instalasi

Clone repository:

```bash
git clone https://github.com/ktaeyvne/archives.git
```

Masuk ke folder project:

```bash
cd archives
```

Install dependency:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```
